# cs50-mario
CS50 Week 1 - Mario Less and Mario More implementation in C.
CS50 – Mario (Week 1)

Overview

This repository contains my implementations of the Mario problem set from Harvard University's CS50 Introduction to Computer Science course.

Problem Set Components

1. Mario Less

A C programming exercise focused on loops, conditional statements and generating a half-pyramid pattern.

2. Mario More

An extended version involving the generation of a double-sided pyramid pattern.

Programming Language

- C

Concepts Practised

- For loops
- While loops
- Conditional statements
- User input validation
- Nested loops
- Problem-solving and algorithmic thinking

Course

CS50 – Introduction to Computer Science, Harvard University.
